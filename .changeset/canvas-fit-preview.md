Add a Canva-style asset panel to the card editor: the Assets tab now opens a left sidebar with the canvas kept visible, thumbnails drag onto the card to insert an image at the drop point (new `insert-image` edit op), and dropping on an `ImagePlaceholder` replaces it. The asset preview dialog gains a canvas-fit mode that overlays the image on the 1080×1350 frame at true relative scale with pixel dimensions and fit status.
